# MusiGen v0.0.4 — Community bug fixes

Thank you to the testers on Discord for the detailed reports behind every fix here.

## Fixed
- **Romanian and other non-Latin-1 lyrics** (ș, ț, Ș, …) no longer stop generation with `'charmap' codec can't encode character`. MusiGen now runs in UTF-8 mode out of the box, so no `.bat` launcher or `PYTHONUTF8` setting is needed.
- **Truly portable runtime.** MusiGen no longer depends on a Python installed on drive C:. Python and its package cache now live inside the MusiGen folder (new `python\` subfolder). This fixes "Setup cannot continue, backend did not start" on PCs that reset C: on reboot, such as Shadow Defender. Existing installs convert themselves on first launch and keep everything already installed. Moving or renaming the MusiGen folder now repairs itself as well.
- **Instrumental songs fill the requested length.** A wordless 180-second request previously planned only about a minute of music. It now plans enough sections for the whole duration.
- **Clear the queue.** "Clear finished" removes done, failed and cancelled jobs, and ✕ removes one. They no longer reappear after a restart. Your songs stay in the Library.
- **Structure chips update the lyrics.** While the lyrics have no words yet, the lyrics box follows the chips as you add, remove or reorder sections. Once lyrics are written, "Apply to lyrics" reorders them to match without losing any text.
- Setup error messages now include the failing step's detail.

## Install / update
Download **MusiGen.zip**. For an existing installation, close MusiGen and replace only **MusiGen.exe**, preserving your **models**, **runtime**, **data** and **music** folders. New users can extract the folder and run the EXE.

On first launch, an existing install moves its Python runtime into the MusiGen folder. This is a one-time download of about 30 MB and takes a few seconds. If you are offline, MusiGen keeps working as before and finishes the move on a later launch.

The ZIP contains only MusiGen.exe, README.txt and LICENSE. It contains no models, runtime, library database or personal music. SHA256SUMS.txt provides the download checksum.

## Known limits
- Style tags such as vocal gender are followed most of the time but not always; on some seeds the model can ignore "male vocal".
- Coming next: a sheet-music view and MIDI export for generated songs.

Validation: frontend build; 33 frontend, 41 backend and 8 packaging tests. Real-model checks on an RTX 4080: a song with Romanian lyrics generated end to end; a 180-second instrumental request planned about 194 seconds of music instead of about 98; the packaged EXE converted an existing C:-based install in about 3 seconds and started normally.
