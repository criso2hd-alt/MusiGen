# MusiGen v0.0.3 — Music-reactive Neon Boutique

## What's new
- Independent, feathered music-lighting zones with alternating patterns, sweeps, neon color changes and a moving MusiGen lettering highlight. Includes an on/off toggle and intensity slider; saved BPM/style guide the show with tempo estimation as a fallback.
- Bass/mid and treble speaker-cone response driven directly by the audio; no repeating animation loop.
- Moodier baked lighting and softened environment reflections. Reflections are approximate and do not reproduce Blender Cycles exactly.
- Record playback waits for the landing animation. Space/right-click toggles play/pause, with an inspection control guide and thinner sleeves.
- Persistent 1–5 star song ratings in the library.
- Caption workflow fixes: timed-phrase mode is selected explicitly, vocal-range seeking helps reveal captions, and recognized-word status explains instrumental gaps.
- Fixed SheetSage2 optional-tool installation failing with missing `REPO_ROOT`; packaged resource paths and the portable app home are handled separately.
- Welcome instructions wait for the lights and do not reopen on capture loss; entry buttons have spacing and readable hover text.

[New screenshots and feature details](https://github.com/criso2hd-alt/MusiGen#new-in-v003)

## Install / update
Download **MusiGen.zip**. For an existing installation, close MusiGen and replace only **MusiGen.exe**, preserving your **models**, **runtime**, **data**, and **music** folders. New users can extract the folder and run the EXE.

The ZIP contains only MusiGen.exe, README.txt and LICENSE. It contains no models, runtime, library database or personal music. SHA256SUMS.txt provides the download checksum.

## Known limits
- Sung-word recognition and timing remain experimental; the real-song worker test produced timestamps, including some coincident word boundaries. Exact karaoke alignment is not guaranteed.
- Environment reflections approximate the room and are not precise mirror reflections. Reduced-motion preferences disable animated lighting and cones.
- Heavy AI generation keeps the 3D store unloaded to preserve GPU resources. Model licenses still apply; YuE2 weights are non-commercial.

Validation: frontend build, 28 frontend tests, 35 backend tests, packaging tests and packaged-asset/ZIP integrity checks. Screenshots are captured from the app, not Blender.
