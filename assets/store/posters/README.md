# Poster textures

Generated with the built-in image-generation tool. Native PNG dimensions: 1122 × 1402 (approximately 4:5). These are flat color artwork, not normal/roughness maps. Use sRGB for the image texture; connect to Base Color. The thin border is printed artwork. Blender scene and app code were not modified.
